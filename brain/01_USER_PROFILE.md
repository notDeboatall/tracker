# 01. User Profile and Seed Data

## Priorities (strict order)
1. **Gym** (6 days/week, 2 hrs; I have been skipping it recently, so protect it hardest)
2. **Java DSA course** (recorded lectures, watch any time)
3. **AIML Python course** (recorded lectures, watch any time)
4. Everything else (ad-hoc work comes in as tasks; see `03_SCHEDULING_RULES.md` for how urgent work interacts with these)

## Fixed life constraints
- College 6 days/week (Mon to Sat).
  - **Mon, Tue, Wed:** 8:00 to 13:00
  - **Thu, Fri, Sat:** 13:00 to 19:00
- Travel by bike: ~25 min one way to college, ~10 min one way to gym.
- Wake 06:30, sleep 22:30 (sleep is a hard boundary; never schedule past it).
- Sunday: no college, no gym.
- Lectures are recorded, so DSA and AIML can be placed in any free slot.

## Minimum versions (the "bad day" safety net)
| Habit | Full | Minimum |
|---|---|---|
| Gym | 120 min | 30 min (warm-up + one main lift) |
| Java DSA | 90 min | 45 min (1 lecture or 2 problems) |
| AIML Python | 90 min Mon-Wed, 60 min Thu-Sat | 30 min (or 1 notebook exercise) |

A day counts as "done" for a habit if the minimum is met.

## Seed template: HOLIDAY (college free day, Mon-Sat)
Same as the normal day, but the college block and its rides are **removed**. The freed hours are available for tasks and habit extension. Gym moves to its preferred time (`morning` by default on holidays). See rules in `03_SCHEDULING_RULES.md`.

## Rules I follow personally
- "Never miss twice": if I skip a habit one day, the next day it is protected.
- Missed block? Move it to a free slot or Sunday. Do not pile it onto tomorrow.
- Gym bag is packed the night before.
